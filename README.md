Corporate Executive CFO Dashboard – Power BI

This project transforms raw financial statements and general ledger data into an executive-level financial analytics dashboard designed for CFOs and senior leadership teams.

Key Features

📊 KPI Cards for:
Gross Profit Margin
Net Profit Margin
Operating Cash Flow

💰 Waterfall Chart to analyze Revenue → Net Income

🌳 Decomposition Tree for Expense Analysis
Region
Department
Expense Category

📈 Year-over-Year (YoY) Growth Analysis

📅 Dedicated Date Table for Time Intelligence

🔍 Hierarchical Drill-Down Navigation

📉 Financial Performance Monitoring and Trend Analysis


Power BI Skills Demonstrated

Data Modeling & Star Schema Design
DAX Measures & Financial Calculations
Time Intelligence Functions
Date Table Creation
Drill-Down & Hierarchical Reporting
Financial KPI Development
Interactive Dashboard Design

Business Objective

Provide executives with a centralized financial command center that enables rapid analysis of profitability, expenses, cash flow, and operational performance while supporting data-driven strategic decisions.
